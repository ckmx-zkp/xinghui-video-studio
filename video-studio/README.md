# 星绘视频工坊

本地自然语言视频创作台，组合 MiniMax-M3、Hailuo 视频 API 与本机 ComfyUI/H3。

## 启动

双击上一级目录的 `启动_星绘视频工坊.bat`，浏览器会打开 `http://127.0.0.1:4175`。脚本会检查 8188 端口，仅在 ComfyUI 未运行时启动它，避免重复进程和数据库锁。

## 创作流程

1. 在聊天框里直接说想拍什么，例如「做玄奘第一集」。
2. 导演缺信息才会追问；默认横屏 18 秒、本机出片，不消耗云端次数。
3. 分镜出现后，把不同参考图点到每一镜的左侧缩略图上。
4. 说「开始拍」会生成本机镜头；说「第三镜头更震撼」只改并重跑第 3 镜。
5. 全部镜头完成后会自动拼接。说「用云端成片」才会消耗每日 3 次额度。

## 额度与安全

- Token Plan 云端视频固定使用 `MiniMax-Hailuo-2.3`、768P、6 秒，每个镜头消耗 1 次视频额度。
- 页面从官方额度接口读取今日与本周用量。
- `.env` 位于上一级目录，API Key 仅由 Node 服务端读取，绝不会发送给浏览器。
- 本地 H3 不消耗云端额度。工坊会把分镜提示词、参考图、画幅映射到已部署的 GGUF 工作流，经 ComfyUI `/prompt` 排队。
- 本机 16GB 显存使用 pruned Q4_K + Qwen3-VL Q2_K + INT8 视频 VAE，而不是官方 INT8/NVFP4 全套（约 40GB）。
- 启动脚本会检查 4175：若工坊已在运行，只打开浏览器，不会再起第二个 Node；也不会关闭已经运行的 ComfyUI。
