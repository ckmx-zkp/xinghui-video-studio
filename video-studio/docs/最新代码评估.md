# 星绘视频工坊：最新本地代码评估

评估日期：2026-08-28

## 结论

项目已从“分镜生成工具”升级为“对话式创作导演”雏形，适合个人 Alpha 测试；暂不适合长期裸公网运行或无人值守批量生成。

## 已验证状态

- M3：真实连接，非演示模式。
- 本地 H3 / ComfyUI：已连接，所需模型文件齐全，非模拟模式。
- 自动测试：13/13 通过。
- `npm run build`、`npm run lint`：通过。
- Git 工作树：评估时干净。

## 优点

### 1. 对话式导演流程已建立

`director.mjs` 将创作拆为“需求访谈 → 简报确认 → 创意方向 → 分镜确认 → 质量审核 → 开拍 → 交付反馈”。用户不需要理解 ComfyUI、节点或工作流。

### 2. 云端额度有前置保护

默认本地生成草稿；云端生成需要完成分镜、质量审核并确认额度。旧的直接生成接口已经禁用，不能绕过项目阶段门禁。

### 3. 项目与逐镜素材可持久化

每个镜头可独立绑定参考图。聊天、简报、分镜、素材、任务状态和成片信息保存在项目目录，刷新页面后仍可继续。

### 4. 本地 H3 自动执行链路已接入

服务端将镜头提示词、画幅、时长、首帧图映射为 ComfyUI `/prompt` 任务，随后轮询、回填镜头，并在全部完成后自动合片。

### 5. 结构化回复与阶段控制较完善

M3 返回的近似 JSON 有修复和重试；项目阶段、镜头编号、素材引用、生成前置条件均由服务端校验，不只依赖前端按钮。

### 6. 已有基础自动测试

测试覆盖导演 JSON 修复、阶段门禁、手机参考图上传、未知项目保护、演示模式隔离等核心逻辑。

## 不足与风险

### 1. 远程访问目前使用明文 HTTP（最高优先级）

阿里云配置使用 Basic Auth，但公网转发地址为 HTTP。Basic Auth 凭据可能在不安全网络上泄露。远程使用前应改为 Tailscale/WireGuard 等私网方案，或至少使用 HTTPS、强密码与防火墙限制。

### 2. `server.mjs` 职责过于集中

该文件同时负责聊天、M3、项目、素材、ComfyUI、Hailuo、任务轮询、合片和远程状态。当前能跑，但持续迭代将难以维护。建议后续拆分为导演服务、项目存储、视频执行器和远程控制 API。

### 3. JSON 文件存储不适合并发

项目状态写入 JSON 文件。手机、浏览器轮询和后台任务并发时，可能出现覆盖或损坏。个人单人测试可接受；远程队列和长期使用前建议迁移至 SQLite。

### 4. 缺少完整真实视频任务验收

当前自动测试未真正调用 M3、Hailuo 或完成一次 H3 生成。代码与服务连接正常不等于成片稳定。应优先执行一次 6 秒单镜头本地 H3 验收，记录耗时、显存、输出时长、自动回填和合片结果。

### 5. 对话流程可能偏重

多轮访谈、简报、创意方向、分镜和质量审核具有专业性，但对“快速做 15 秒短视频”可能步骤过多。建议增加快速创作模式：一句话生成默认方案，用户仅确认一次即可开拍。

### 6. 合片缺少重新编码回退

目前优先使用无重新编码拼接；如果不同镜头编码参数不一致，可能失败。应在失败时自动转码后再合并。

### 7. 生成管理能力不足

暂缺暂停、取消、重试次数、排队顺序、预计时间和用户友好的失败原因解释。白天远程运行时，这些能力很重要。
