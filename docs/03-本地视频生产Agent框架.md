# 本地视频生产 Agent 框架

给第一次做「本地 Agent」的人：这套东西算不算本地 Agent、骨架是什么、怎样从设计走到可验收。

## 1. 它算不算「本地 Agent 开发」？

**算，但是混合体，不要理解成「所有模型都在本机」。**

| 部分 | 在哪跑 | 职责 |
|---|---|---|
| 编排 Agent（星绘工坊） | 本机 Node `4175` | 状态机、工具调用、项目记忆、门禁 |
| 导演模型 | 云端 MiniMax-M3 | 理解需求、给见解和选项 |
| 视频工人 | 本机 ComfyUI + H3，或云端 Hailuo | 按镜头出视频 |
| 远程入口 | 阿里云只转发到 4175 | 上班时用手机下单，计算仍在家里 |

符合本地 Agent 开发的典型内容：

- 有一个 **长期运行的本地运行时**（工坊 + 可选 GPU）。
- 有 **工具**：写简报、出分镜、提交 Comfy、轮询、合片、管额度。
- 有 **记忆**：`outputs/projects/` 里的对话、素材、阶段。
- 有 **人机环**：每轮见解 + 2–4 个选项 + 自由输入，关键步骤要人确认。
- 用户 **不直接操作工具内部**（不看节点图）。

不符合「纯本地大模型 Agent」的部分：

- 导演脑不是本地 LLM，断网且未开 `STUDIO_DIRECTOR_DEMO_MODE` 就没有访谈。
- 视频工人可以是云端 Hailuo（有额度时）。
- Agent **不能**在聊天里自主开拍；这是产品约束，不是技术做不到。

如果任务书写的是「在本机做一条能对话、能调用本地工具出视频的 Agent」，当前仓库就是这份作业的正确形态。如果任务书写的是「离线私有化全部模型」，还差本地导演模型和满血 H3。

## 3. 设计原则（做这类 Agent 时优先遵守）

1. **模型提议，服务端拍板。** `actions` 只是请求；`phase` 在服务端变。否则模型一胡说就会跳过评审去烧 GPU。
2. **危险工具单独入口。** 开拍、云端扣次、合片不要藏在聊天 JSON 里偷偷执行。
3. **分层可测。** 无 GPU 测访谈和门禁；有 GPU 再测出片；常规测试禁止真交 Hailuo。
4. **失败要显式。** H3 没装好时是「本机生成不可用」，不是整站 500。
5. **用户语言里没有实现细节。** 不说 Comfy、GGUF、节点、8188。
6. **密钥只在服务端。** `.env` 不进 Git。

阶段机：

| 阶段 | 人做什么 | Agent 做什么 | 禁止 |
|---|---|---|---|
| discovery | 回答问题、选选项、传图 | 更新简报、每轮一个问题 | 出分镜、开拍 |
| brief_review | 确认或打回简报 | 解释简报 | 用聊天代替确认 |
| concept_selection | 选一个创意方向 | 给 3 套方向、可换一批 | 跳过选择 |
| storyboard_review | 改某一镜、确认分镜 | 重写镜头提示词 | 开拍 |
| quality_review | 通过或返回 | 解释风险 | 开拍 |
| ready_to_generate | 点开拍（云端要确认次数） | 组图、排队 | 聊天里 generate |
| generating | 等 | 轮询、回填 | 重复提交 |
| delivery_review | 接受或返修 | 合片、展示 | 清素材 |
| delivered | 只看总结 | 只回答 | 改已交付状态除非返修 |

## 4. 开发顺序（建议一次只做一层）

1. **空转编排：** 演示模式下把阶段走通，测试全绿。  
2. **接真实 M3：** 关导演演示，开视频演示；确认 JSON 解析和选项可点。  
3. **接素材：** 上传图、分镜绑定、多模态内容进 M3。  
4. **接 H3：** 按文档 01 部署，mock Comfy 测编排，再在 GPU 上真出一条。  
5. **接 Hailuo：** 人工点一次额度确认即可，不要写进 CI。  
6. **远程转发：** 本机已稳定后再开隧道，阿里云不要承担导演逻辑。

每层的「完成」以文档 01、02 的勾选为准，不要跨层一起改。

## 5. 完成定义（整条 Agent）

产品可用：

- [ ] 新人只看这三份文档 + `依赖与部署.md` + `AGENTS.md` 能在本机把工坊跑起来。
- [ ] 无 GPU 机器能演示完整创作门禁。
- [ ] GPU 机器能从「确认分镜 → 开拍 → 预览 → 合片」打通至少一条本地成片。
- [ ] 远程 PWA 能对话并看到同一项目（电脑开着且隧道活着）。
- [ ] Git 无密钥、无模型、无 `outputs/`。

仍明确不算完成：

- 效果追平 MiniMax Design 云端成片。
- 纯离线（本机导演模型）。
- 可信 HTTPS 安装版 PWA。
- 自动配音字幕、角色身份库、无缝 15 秒以上单段。

## 6. 给下一个 Agent 的工作方式

- 先读 `AGENTS.md` 的门禁，再改代码。
- 改 UI 后看桌面和手机；改导演契约后补 `test/workflow.test.mjs`。
- 不要为了「快」让聊天直接 `generate`。
- 不要把 Comfy 节点实验提交进默认开拍图，除非同时改测试和文档 01。
- 长任务用本机开机脚本，不要依赖某个 IDE 会话里的后台进程。
